SkyMissions

Review player information, unlocked achievements, completed missions, titles, and owned SkyPoints; accept randomized or mod-authored missions and spend points in SkyStore.

App tabs

  • Dashboard includes Overview, Factions, Properties, Name Cards, and Titles. Overview shows player details, recent actions, completed missions, and owned SkyPoints.
  • SkyMissions displays twelve randomized offers in a four-column, three-row desktop grid. A completed offer is replaced with one new offer.
  • SkyStore contains rotating game items, name cards, manifest-contributed offers, and offers registered by native plugins through the SkyMissions API.

Mission behavior

Missions are generated by SkyMissions from SkyRewrite gameplay events; SkyRewrite is required by this app, but not by SkyOS Core. SkyMissions does not import Skyrim quest objectives. Offers can target hostile groups individually, including Afflicted, bandits, Forsworn, ghosts, Reavers, warlock mage types, Penitus Oculatus, vampires, witches, and hostile creatures. Other offers request named ingredients, potion crafting or a particular potion, general or named smithing, or pelts and hides. Enemy-specific offers count hostile kills; ingredient offers count item pickups or looting; crafting offers count SkyRewrite potion-crafted or item-smithed records. Mission progress and SkyPoints are stored per character. Registered missions use event type and optional FormID, subject, or identity filters to count matching SkyRewrite records.

Native mission and SkyStore API

The standalone SkyMissions project ships SkyMissionsAPI.h and its guide with the app for SKSE plugin authors. Plugins can register player-accepted missions that reward SkyPoints and offers that appear in SkyStore. A purchase is broadcast to SKSE listeners with the owner ID, offer ID, name, and price; the owning plugin grants the purchased content. See SkyMissions API Guide.html for the C ABI, examples, limits, and fulfillment flow. Plugins using named SkyRewrite event constants also need the separate SkyRewrite API Header.

SkyViewer options

Open SkyViewer → SkyMissions to choose the player-card format, player-name color and font, and the completion notice's visibility, one of three designs, and one of nine positions.

SkyStore offers for modders

Add a skyStoreOffers array to your SkyViewer module manifest. Each offer needs a stable unique ID, name, and non-negative integer price. Optional description and image fields add display details. Purchases are saved as character entitlements and sent to the SkyOS host with the module and offer IDs so the owning app can provide the feature.

{
  "skyStoreOffers": [
    { "id": "example-feature", "name": "Example Feature", "description": "A feature supplied by ExampleMod.", "price": 750, "image": "" }
  ]
}
